# Movie-Recommendation-System
Aim : It utilises collaborative filtering techniques to analyse user preferences and similarities 
among movies to generate accurate and relevant movies recommendations.The Movie Recommendation System is a machine learning-based application that 
provides personalised movie recommendations to users. It utilises collaborative filtering 
techniques to analyse user preferences and similarities among movies to generate accurate and 
relevant recommendations. The system is built using Python programming language and 
incorporates popular machine learning libraries such as scikit-learn and pandas.

# Description 
This repository showcases a Movie Recommendation System that integrates machine learning, interactive web development, and external APIs to deliver personalized film suggestions. At its foundation, the system employs machine learning models such as collaborative filtering and content-based filtering to analyze user preferences, ratings, and movie metadata, enabling accurate prediction of movies users are likely to enjoy. To make the project accessible and visually appealing, a Streamlit application is built, providing an intuitive interface where users can explore recommendations, search for titles, and interact with the system in real time. Additionally, the project leverages the TMDB (The Movie Database) API through secure API keys to fetch dynamic movie details including posters, descriptions, release dates, and ratings, enriching the recommendations with real-world context. This end-to-end pipeline demonstrates how data science, machine learning, and modern web frameworks can be combined to create a professional, user-friendly recommendation platform suitable for deployment and portfolio presentation.
